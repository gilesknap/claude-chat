Notes

A blank Where means the repository isn't in regular use — thirteen of the twenty-seven. May is the busiest month at nine new repositories, but only three of those nine stuck.

claude-sandbox appears twice, deliberately. DiamondLightSource/claude-sandbox is the master copy even though GitHub still marks it a fork, so it is kept and carries the marker; the May original is listed unmarked as the superseded origin.

Three real forks are excluded: ibek-runtime-support, ibek-support and python-copier-template. argocd-monitor, ioc-adsimdetector, pkm-vault-demo and pkm-vault-dg carry no repository description; the first is inferred from its name and early commits, the rest are left blank.

Repositories under epics-containers and DiamondLightSource are attributed by first-commit author, since GitHub records no creator; only public ones are visible. PR counts come from GitHub search and cover public repositories plus private ones the token can reach. Counts are pull requests opened, which measures volume, not size or difficulty — and the data shows the rise, not its cause.
